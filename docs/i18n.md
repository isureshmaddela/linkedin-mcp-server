# Languages

Aira's screens are offered in **English, Telugu (తెలుగు) and Hindi (हिन्दी)**. Each person picks their language
from the globe button in the top bar (or on the sign-in screen and public pages), or under Display and reading.
The choice is kept on the device and, for the everyday apps, with the person's profile, so it follows them.

## How it works

* Every screen is written in English. `scripts/i18n_extract.py` collects every string a person can see (the
  browser screens, the server's messages and labels, the apps' built-in content such as trivia and starter decks)
  into `auto_apply_assistant/i18n/catalog.json`. Text with a number or name in it becomes a pattern:
  `` `${n} new headlines` `` is `{0} new headlines`.
* `auto_apply_assistant/i18n/te.json` and `hi.json` map each English string to its translation (hand-written,
  checked by `scripts/i18n_check.py`: every string present, placeholders kept, the right script used).
* `auto_apply_assistant/i18n.js` translates what is on the page: a MutationObserver translates new text, button
  labels, placeholders, tooltips and spoken labels before the browser paints them, so every screen (including ones
  built later) needs nothing special. Exact matches first, then patterns; a pattern with little fixed text
  ("{0} of {1}") only applies when its gaps hold numbers or known words, and an English plural ending is not
  carried into the translation. The English original is kept, so switching language (back to English too) needs
  no reload.
* Dates and numbers use the language's locale (`te-IN`, `hi-IN`); `<html lang>` follows the choice, so screen
  readers and the read-aloud voice speak it.
* Text people wrote themselves (names, messages, posts) has no entry and stays as written. Mark an area
  `translate="no"` to be sure it is never changed.
* News headlines come in the reader's language from the source (Google News in Telugu and Hindi).

## Changing text

After adding or changing visible text:

```
uv run python scripts/i18n_extract.py          # refresh the catalog
uv run python scripts/i18n_check.py te         # lists strings without a Telugu translation
uv run python scripts/i18n_check.py hi
```

Add the missing translations to `te.json` and `hi.json` (or put them in `i18n/work/<lang>-<n>.json` and run
`uv run python scripts/i18n_merge.py te hi`). `tests/test_i18n.py` fails when the catalog is stale or more than
1% of it is untranslated.

## Adding a language

1. Add it to `LANGUAGES` in `aira/i18n.py` and in `auto_apply_assistant/i18n.js` (code, English name, native name,
   locale, direction).
2. Add its script range to `scripts/i18n_check.py` and write `auto_apply_assistant/i18n/<code>.json` for every
   string in the catalog.
3. News: add the language and its regions to `aira/suite/news/feeds.py`.
